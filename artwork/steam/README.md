# Steam artwork

Artwork for StillStream as a non-Steam game in your Steam library, so it looks at home in
Steam Gaming Mode and Big Picture.

| File | Steam slot | Size |
| --- | --- | --- |
| `library-capsule-600x900.png` | Portrait capsule (library grid) | 600 × 900 |
| `header-capsule-920x430.png` | Wide capsule (recent games, landscape grid) | 920 × 430 |
| `library-hero-3840x1240.png` | Hero (banner behind the game page) | 3840 × 1240 |
| `logo-1669x320.png` | Logo (over the hero, transparent) | 1669 × 320 |
| `icon-512.png` | Icon | 512 × 512 |

## Set them in Steam

In Desktop Mode, after adding StillStream with **Games → Add a Non-Steam Game to My Library**:

1. Download the files from this folder.
2. In the Steam library, open StillStream's page. Right-click the empty banner area at the top
   and choose **Set Custom Background** for the hero, then **Set Custom Logo** for the logo.
3. In the library grid, right-click StillStream → **Manage → Set custom artwork** and pick the
   portrait capsule. Switch the grid to the landscape view and do the same with the wide capsule.
4. Right-click StillStream → **Properties**, click the icon square next to the name and pick
   `icon-512.png`.

Tools such as Steam ROM Manager or the Decky plugin SteamGridDB can apply the same files.
